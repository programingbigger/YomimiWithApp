案2 の良いところ・気になるところ

  • 良い：画面は「名刺」と「シート」の2つだけ。迷う場所がない
  • 良い：本棚の部品（検索・StatusFilterChip・BookCoverView・StatusBadgeView）をほぼそのまま使える
  • 良い：Notion のチェックリスト「グリッドで選択／解除、選んだ順の番号を表示」とそのまま一致
  • 気になる（→解決）：下へスクロールすると、最初に選んだ本が見えなくなる
  • 追加：画面下の 「選択中だけ見る」 で、選んだ本だけを ①→⑩ の順に表示。何を選んだかの確認と、名刺の並びのプレビューを兼ねる
  • 置き場所を下にした理由：「何冊選んだか」の隣にあると意味が伝わりやすく、親指も届く。ステータスのチップとは役割が違うので、チップの列には混ぜない
  • オンのまま本をタップすると外れて、一覧から消える。0冊になったら自動でオフ

SwiftUI ではこう作る（案2）

  • シート：.sheet(isPresented:)。中身は本棚の LazyVGrid とほぼ同じ
  • 番号：表紙に .overlay(alignment: .topTrailing) で丸い数字を重ねる
  • 下の完了ボタン：.safeAreaInset(edge: .bottom) で画面の下に固定
  • キャンセルしたら selectedIDs を捨てるだけ。名刺側の状態は変わらない
  • 「選択中だけ見る」は @State var showSelectedOnly = false を1つ足して、表示する配列を切り替えるだけ（下）
private var displayedBooks: [BookRecord] {
    let base = filteredBooks          // 検索・チップで絞った本
    guard showSelectedOnly else { return base }
    // 選んだ順（selectedIDs の並び）に並べ直す
    return selectedIDs.compactMap { id in
        base.first { $0.id == id }
    }
}
BookCoverView(title: book.title, thumbnailURL: book.thumbnailURL)

        }
    }
    .onTapGesture { withAnimation(.spring) { toggle(book) } }

v2 から直したところ（今の実装に合わせた）

  • タブバーは「本棚／お楽しみ／📷／名刺／設定」の5つ。カメラは中央に浮く丸ボタン（HomeView）
  • 本棚のステータスは表紙の点ではなく、タイトル下のバッジ（StatusBadgeView）。凡例は削除
  • チップは「すべて 18」の形。選択中は茶色、それ以外は白（StatusFilterChip）
  • ステータス名は「読みたい！」、並びは 読了→読中→積読→読みたい！（ReadStatus）
  • 書影のない本は、タイトル入りの白いプレースホルダー（BookCoverView）
  • 本棚のヒント行「💡読み終わったら…」を追加
  • 名刺は 4列 → 3列×最大4行。自己紹介文の欄はなくした（F-07・2026-11-07 の方針）。タイトルの2択は名刺画面ではなく、S-08 でハッシュタグとして選ぶ（2026-11-07 案B）
  • 色は Assets の値に統一（AccentMid は #C49A6A）
  • モックでは検索欄で実際に絞り込める。今のアプリでは検索文字がまだ filteredBooks に入っていないので、実装時に接続が必要
